# algorithm-solutions
LeetCode 풀이 기록 | C++ | 문제별 접근법 정리

# 목적
AI를 자주 사용하다보니 문제를 해결하는 방식이 너무 AI에 의존되어있다고 느끼게 됨

예를 들어, 문제가 나옴 -> 막힘 -> 바로 AI에게 질문함

문제를 빠르게 해결하려고 하다보니 스스로 해당 문제에 대해 고민하는 과정이 빠지게 됨

습관으로 굳어지면 고치기 어려울 거 같아 매일 코딩테스트를 풀며 문제에 대해 고민하는 과정을 연습하려고 함

# 목표
1. 고민하는 시간 꼭 지키기
2. 매일 1문제 이상 풀기
3. leetcode-kit(9400coin) 구매

# 나만의 Rules
### 1. 고민은 20분
- 최소 20분 정도는 스스로 고민해보기
- 20분은 고민하는 시간임. 20분 안에 구현까지 하겠다는 뜻은 아님

### 2. 코드보다 글이 먼저
- 고민했던 과정이랑 문제 접근법을 먼저 글로 써보기
- 코드보다 내 생각을 글로 써보는게 더 중요함

### 3. 20분은 마감이 아니라 기준
- 시간 규칙은 맹목적으로 지킬 필요 없음. 20분이 지났어도 고민해서 풀 수 있다고 생각이 들면 더 투자해서 고민해보기
- 20분 고민해도 해결이 안 될 것 같으면 쓸 수 있는 도구를 적극적으로 써서 문제 해결하기
